## Selected projects

### [Hong Kong Airbnb — Geography of Preference](https://github.com/WuqianMa/Group-Projects-AI-and-Society)
**Interactive data analysis · Geospatial visualization · Group project**

[Live dashboard](https://0-sigma-puce.vercel.app) · [Repository](https://github.com/WuqianMa/Group-Projects-AI-and-Society)

An exploratory dashboard using Hong Kong Airbnb listing and review data. It brings together district-level maps, review-density comparisons, room-type breakdowns, and review-topic visualizations. Visitors can explore different geographic areas and review segments.

**Tools:** JavaScript, Leaflet, Apache ECharts, GeoJSON, Vercel.

### [NewsLab — Controlled News-Feed Experiments](https://github.com/WuqianMa/NewsLab-Controlled-News-Feed-Experiments-in-the-Browser)
**Research software · Behavioral experiments · AI-assisted development**

[Repository and demos](https://github.com/WuqianMa/NewsLab-Controlled-News-Feed-Experiments-in-the-Browser)

A prototype for designing browser-based news-feed experiments, managing experimental conditions, recording participant interactions, and exporting research data. The project was developed through an AI-agent-assisted coding workflow; the repository documents how the agents were used.

**Focus:** Experimental design, event collection, research workflows, full-stack prototyping.

### [LLM Citation-Hallucination Evaluation](https://github.com/WuqianMa/LLM-agent-EUcourt)
**LLM evaluation · AI governance · Reproducible experiments**

[Repository](https://github.com/WuqianMa/LLM-agent-EUcourt)

An exploratory framework for checking legal references made by simulated prosecutor, defense, and judge agents against a local corpus of EU regulations. Includes prompts, a deterministic citation checker, and example transcripts. Initial runs are illustrative rather than statistically conclusive.

**Focus:** Evaluation design, citation verification, multi-agent workflows, EU digital regulation.

### [E-commerce CI/CD — Coursework Project](https://github.com/WuqianMa/e-commerce-CI-CD)
**Software engineering · Testing · Deployment**

[Repository](https://github.com/WuqianMa/e-commerce-CI-CD)

A course project exploring a Django web application with containerization, automated tests, and GitHub Actions.

**Tools:** Python, Django, Docker, GitHub Actions.
